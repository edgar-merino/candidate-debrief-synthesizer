# L3 Coding Behavioral Anchors (Cloud AI Engineer / TSC)

## Core Competencies

### 1. Problem Understanding & Core Algorithm Implementation
- **Positive Signals:**
  - Clarifies basic input/output expectations and translates a straightforward problem into a correct working solution.
  - Identifies basic time and space complexity (e.g., O(n), O(n log n), O(n²)) and improves an obvious inefficiency with light prompting.
- **Negative Signals:**
  - Misunderstands core problem constraints or gets stuck implementing basic data structure operations (maps, lists, sets, loops).
  - Cannot reason about runtime or memory growth even on simple loops.

### 2. Code Readability & Language Fundamentals
- **Positive Signals:**
  - Writes clean, syntactically sound code using clear variable names and basic helper functions to avoid duplication.
  - Demonstrates solid fluency in their chosen language's standard library.
- **Negative Signals:**
  - Produces fragmented or syntactically broken code that requires heavy interviewer intervention to fix.
  - Uses confusing control flow or ignores basic language idioms.

### 3. Basic Edge Cases & Manual Tracing
- **Positive Signals:**
  - Walks through a sample input step-by-step to verify correctness and checks common edge cases (empty input, single element, null/None).
  - Locates and fixes simple bugs once spotted during a dry run.
- **Negative Signals:**
  - Skips tracing their code and misses obvious off-by-one or null-handling errors.
  - Makes random edits instead of reasoning through program state when debugging.

### 4. Communication & Receptiveness to Feedback
- **Positive Signals:**
  - Explains their plan before coding and narrates key decisions clearly.
  - Takes interviewer hints smoothly and incorporates feedback without losing track of the solution.
- **Negative Signals:**
  - Remains silent for long stretches or cannot explain what their own code does.
  - Disregards interviewer nudges or becomes stuck without asking clarifying questions.
