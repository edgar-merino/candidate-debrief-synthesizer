# L4 Coding Behavioral Anchors (Cloud AI Engineer / TSC)

## Core Competencies

### 1. Problem Decomposition & Algorithmic Reasoning
- **Positive Signals:**
  - Clarifies input/output types, constraints, and edge cases before coding.
  - Arrives at a working brute-force or optimal approach and accurately states time and space complexity with minimal nudging.
- **Negative Signals:**
  - Starts writing code immediately without validating assumptions or problem boundaries.
  - Struggles to trace basic data structure operations or miscalculates time/space complexity even after hints.

### 2. Code Quality, Clarity & Idiomatic Style
- **Positive Signals:**
  - Writes clean, readable, modular code with meaningful variable/function names and idiomatic language constructs.
  - Handles core error cases and avoids tangled control flow.
- **Negative Signals:**
  - Produces brittle, repetitive, or hard-to-follow code with syntax/API errors that stall progress.
  - Leaves significant dead code or unaddressed bugs without recognizing them.

### 3. Edge-Case Handling & Verification
- **Positive Signals:**
  - Proactively dry-runs code against normal and boundary inputs (empty input, duplicates, null/None, large values).
  - Spots and fixes off-by-one or state bugs systematically when stepping through an example.
- **Negative Signals:**
  - Declares the solution "done" without tracing a single test case.
  - Relies on random trial-and-error edits rather than diagnosing root causes when bugs appear.

### 4. Technical Communication & Collaboration
- **Positive Signals:**
  - Explains reasoning clearly while coding and incorporates interviewer feedback constructively.
  - Keeps track of trade-offs when asked to optimize or refactor.
- **Negative Signals:**
  - Codes in prolonged silence even when asked to talk through their approach.
  - Becomes defensive or ignores direct feedback about bugs or constraints.
